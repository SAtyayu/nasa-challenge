# Setup

Full install and run instructions live in the [repo README](https://github.com/SAtyayu/nasa-challenge) — this page is a quick pointer, not a duplicate.

```bash
git clone https://github.com/SAtyayu/nasa-challenge.git
cd nasa-challenge
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). The dashboard itself is not hosted anywhere — it's meant to be run locally. Only this documentation is published, via GitHub Pages.
